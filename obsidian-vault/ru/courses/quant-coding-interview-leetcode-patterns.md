# Алгоритмические Паттерны LeetCode для Квант-Разработчиков

Ключевые алгоритмы для секций CoderPad / LeetCode на собеседованиях в Citadel Securities, IMC и Hudson River Trading.

---

## Ключевые Паттерны

1. **Monotonic Stack (Монотонный стек):** Оптимизация поиска ближайших меньших/больших элементов за $O(N)$ (например, задача о гистограмме).
2. **Sliding Window:** Обновление агрегатов скользящего окна в стакане ордеров за $O(1)$.
3. **Бинарный поиск по ответу:** Поиск оптимального порогового значения в условиях монотонности.
