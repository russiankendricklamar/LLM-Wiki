# Теория перколяции (Percolation Theory)

**Теория перколяции (просачивания)** — это раздел статистической физики и теории графов, изучающий поведение случайных связных систем при изменении концентрации узлов или связей. Перколяция является наипростейшей геометрической моделью **непрерывного фазового перехода (второго рода)**.

---

## 1. Решеточная модель перколяции и Критический Порог ($p_c$)

Рассмотрим решетку размера $L \times L$, в которой каждая ячейка (или ребро) с вероятностью $p$ независимым образом является «открытой» (проводящей), а с вероятностью $1 - p$ — «закрытой».

- **Узловая перколяция (Site Percolation):** Случайным образом заполняются узлы.
- **Связевая перколяция (Bond Percolation):** Случайным образом заполняются ребра.

**Критический порог перколяции ($p_c$):** Значение вероятности $p$, при превышении которого в бесконечной решетке впервые возникает **бесконечный (перколяционный) кластер**, пронизывающий всю систему от одного края до другого.

| Топология решетки | Узловая $p_c^{site}$ | Связевая $p_c^{bond}$ |
| :--- | :--- | :--- |
| **2D Квадратная (Square)** | $0.592746$ | **$0.500000$** (Точно) |
| **2D Треугольная (Triangular)** | **$0.500000$** (Точно) | $2 \sin(\pi/18) \approx 0.347296$ |
| **3D Кубическая (Cubic)** | $0.311608$ | $0.248812$ |

---

## 2. Параметр порядка и Критические Индексы (Critical Exponents)

В окрестности критической точки $p \to p_c^+$ системные характеристики подчиняются степенным законам (Scaling Laws):

1. **Мощность бесконечного кластера $P(p)$ (Параметр порядка):**
   $$P(p) \propto (p - p_c)^\beta, \quad \text{при } p > p_c$$
2. **Средний размер конечных кластеров $S(p)$:**
   $$S(p) \propto |p - p_c|^{-\gamma}$$
3. **Радиус корреляции (размер наибольшего конечного кластера) $\xi(p)$:**
   $$\xi(p) \propto |p - p_c|^{-\nu}$$

> **Гипотеза универсальности:** Критические индексы ($\beta, \gamma, \nu$) зависят только от размерности пространства $d$, но **не зависят** от конкретной геометрии решетки (квадратная, треугольная или сотовая). В 2D: $\beta = 5/36 \approx 0.138, \gamma = 43/18, \nu = 4/3$.

## 3. Симуляция перколяции на Python

```python
import numpy as np
from scipy.ndimage import label

def simulate_percolation(grid_size: int, p: float) -> tuple[bool, int]:
    """Симулирует узловую перколяцию на 2D квадратной сетке."""
    # Создаем случайную сетку: 1 с вероятностью p, 0 с вероятностью 1-p
    grid = (np.random.rand(grid_size, grid_size) < p).astype(int)
    
    # Находим связные компоненты (кластеры)
    labeled_grid, num_features = label(grid)
    
    # Проверяем наличие перколяции (соединение верхнего и нижнего краев)
    top_row_labels = set(labeled_grid[0, :]) - {0}
    bottom_row_labels = set(labeled_grid[-1, :]) - {0}
    
    has_percolated = bool(top_row_labels.intersection(bottom_row_labels))
    return has_percolated, num_features

# Тест в окрестности p_c ≈ 0.5927
p_test = 0.60
percolated, num_clusters = simulate_percolation(grid_size=200, p=p_test)
print(f"При p = {p_test}: Перколяционный кластер создан? {percolated}. Всего кластеров: {num_clusters}")
```
