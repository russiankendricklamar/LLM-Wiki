# Вейвлет-преобразование (Wavelet Transform)

**Вейвлет-преобразование** — это математический метод спектрально-временного анализа сигналов, преодолевающий ключевой недостаток Преобразования Фурье: Фурье-анализ дает идеальную частотную локализацию, но полностью теряет временную информацию. Вейвлеты (маленькие волны) позволяют одновременно анализировать как частотный состав сигнала, так и время наступления конкретных частотных событий.

---

## 1. Материнский вейвлет и Непрерывное Вейвлет-Преобразование (CWT)

Основой является материнский вейвлет $\psi(t) \in L^2(\mathbb{R})$ — функция с нулевым средним:
$$\int_{-\infty}^{\infty} \psi(t) dt = 0$$

Семейство вейвлетов получается путем сдвига (translation) $b$ и масштабирования (scaling) $a$:

$$\psi_{a, b}(t) = \frac{1}{\sqrt{|a|}} \psi\left( \frac{t - b}{a} \right)$$

**Непрерывное вейвлет-преобразование (CWT)** сигнала $x(t)$:

$$CWT_x(a, b) = \int_{-\infty}^{\infty} x(t) \psi_{a, b}^*(t) dt = \frac{1}{\sqrt{|a|}} \int_{-\infty}^{\infty} x(t) \psi^*\left( \frac{t - b}{a} \right) dt$$

## 2. Дискретное Вейвлет-Преобразование (DWT) и Мультиразрешающий Анализ

Для вычислений на компьютере параметры выбираются по двоичной сетке $a = 2^j, b = k \cdot 2^j$:

$$\psi_{j, k}(t) = 2^{-j/2} \psi(2^{-j} t - k)$$

**Мультиразрешающий анализ (MRA, Малла):**
Сигнал раскладывается на аппроксимирующие (низкочастотные) $A_j$ и детализирующие (высокочастотные) $D_j$ коэффициенты с помощью пар зеркальных фильтров (Quadrature Mirror Filters).

```python
import pywt
import numpy as np

# Генерация временного ряда с резким скачком волатильности
t = np.linspace(0, 1, 1024)
signal = np.sin(2 * np.pi * 10 * t) + (t > 0.5) * np.sin(2 * np.pi * 50 * t)

# Дискретное вейвлет-преобразование с вейвлетом Добеши (db4)
coeffs = pywt.wavedec(signal, 'db4', level=4)
cA4, cD4, cD3, cD2, cD1 = coeffs

print(f"Форма аппроксимирующих коэффициентов cA4: {cA4.shape}")
print(f"Форма детализирующих коэффициентов cD1: {cD1.shape}")
```
