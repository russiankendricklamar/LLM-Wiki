# Оценка Опционов Методом Монте-Карло и Снижение Дисперсии

Метод Монте-Карло применяется для численной оценки экзотических опционов, не имеющих аналитического решения (например, Азиатские опционы с усреднением цены).

---

## 1. Базовый метод Монте-Карло

Симуляция траектории Геометрического Броуновского Движения (GBM):
$$S_T = S_0 \exp \left( (r - \frac{1}{2}\sigma^2)T + \sigma \sqrt{T} Z \right), \quad Z \sim N(0, 1)$$

Оценка цены опциона Call:
$$\hat{V}_0 = e^{-rT} \frac{1}{N} \sum_{i=1}^N \max(S_T^{(i)} - K, 0)$$

---

## 2. Методы Снижения Дисперсии (Variance Reduction)

### 2.1 Антитетические Переменные (Antithetic Variates)
Для каждого случайного числа $Z^{(i)}$ создается параллельная траектория с $-Z^{(i)}$. Это создает отрицательную ковариацию и резко снижает стандартную ошибку оценки:
$$Var \left( \frac{X + X'}{2} \right) = \frac{1}{2} Var(X) + \frac{1}{2} Cov(X, X')$$

### 2.2 Управляющие Переменные (Control Variates)
Использование известного аналитического решения стандартного европейского опциона для корректировки оценки экзотического опциона.
