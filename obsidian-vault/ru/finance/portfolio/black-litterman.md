# Модель Блэка — Литтермана (Black-Litterman Model)

Модель Блэка — Литтермана — это математический фреймворк портфельного инвестирования, разработанный Фишером Блэком и Робертом Литтерманом в Goldman Sachs (1990). Модель объединяет теорию портфеля Марковица (Mean-Variance Optimization) с байесовским анализом, избавляя классическую оптимизацию от экстремальной чувствительности к входным параметрам (проблема "Estimation Error Maximizer").

---

## 1. Проблема классической оптимизации Марковица
Традиционная оптимизация Марковица требует на вход вектор ожидаемых доходностей $\mu$ и ковариационную матрицу $\Sigma$. На практике оценка $\mu$ по историческим данным содержит сильный шум, что приводит к:
1. **Экстремальной концентрации весов:** Модель назначает 100% капитала в 1-2 актива с наилучшей исторической доходностью.
2. **Нестабильности весов:** Минимальные изменения в входящих данных вызывают радикальные перестановки портфеля.

---

## 2. Математическая механика: Обратная оптимизация (Implied Equilibrium Returns)

Модель Блэка — Литтермана начинает с **равновесных доходностей (Implied Equilibrium Excess Returns)** $\Pi$, выведенных через обратное решение задачи Марковица для рыночного портфеля с весами $w_{mkt}$:

$$\Pi = \delta \Sigma w_{mkt}$$

где:
- $\delta = \frac{E(R_m) - R_f}{\sigma_m^2}$ — коэффициент аверсии к риску (Risk Aversion Coefficient),
- $\Sigma$ — ковариационная матрица доходностей активов,
- $w_{mkt}$ — капитализационные веса активов на глобальном рынке.

---

## 3. Интеграция субъективных взглядов инвестора (Views)

Инвестор формирует $k$ специфических прогнозов (взглядов) над $N$ активами:
- **Абсолютный взгляд:** *«Актив A принесёт 8%»*
- **Относительный взгляд:** *«Актив B превзойдет актив C на 3%»*

Взгляды кодируются матрицей $P \in \mathbb{R}^{k \times N}$, вектором ожидаемых величин $Q \in \mathbb{R}^k$ и диагональной матрицей неопределенности $\Omega \in \mathbb{R}^{k \times k}$:

$$P \cdot \mu \sim \mathcal{N}(Q, \Omega)$$

---

## 4. Байесовское объединение: Априорное и Апостериорное распределение

Априорное распределение доходностей берется как равновесное с неопределенностью $\tau \Sigma$:
$$\mu \sim \mathcal{N}(\Pi, \tau \Sigma)$$

Используя формулу Байеса для нормальных распределений, **апостериорный вектор ожидаемых доходностей** $\bar{\mu}$ и **апостериорная ковариационная матрица** $\bar{\Sigma}$ принимают вид:

$$\bar{\mu} = \left[ (\tau \Sigma)^{-1} + P^T \Omega^{-1} P \right]^{-1} \left[ (\tau \Sigma)^{-1} \Pi + P^T \Omega^{-1} Q \right]$$

$$\bar{\Sigma} = \Sigma + \left[ (\tau \Sigma)^{-1} + P^T \Omega^{-1} P \right]^{-1}$$

---

## 5. Итоговая оптимизация весов
Итоговые оптимизированные веса портфеля рассчитываются по классической формуле с использованием апостериорных параметров:

$$w^* = \frac{1}{\delta} \bar{\Sigma}^{-1} \bar{\mu}$$

---

## 6. Реализация на Python / NumPy

```python
import numpy as np

def black_litterman(
    w_mkt: np.ndarray, 
    sigma: np.ndarray, 
    P: np.ndarray, 
    Q: np.ndarray, 
    delta: float = 2.5, 
    tau: float = 0.05, 
    omega: np.ndarray = None
) -> tuple[np.ndarray, np.ndarray]:
    """
    Вычисляет апостериорные доходности и ковариационную матрицу Блэка-Литтермана.
    """
    # 1. Подразумеваемые равновесные доходности
    pi = delta * sigma @ w_mkt
    
    # 2. Если Omega не задана, используем каноническую диагональ Хейна-Литтермана
    if omega is None:
        omega = np.diag(np.diag(tau * P @ sigma @ P.T))
        
    # 3. Апостериорный вектор доходностей (Bayesian Master Equation)
    inv_tau_sigma = np.linalg.inv(tau * sigma)
    inv_omega = np.linalg.inv(omega)
    
    post_cov_prior = np.linalg.inv(inv_tau_sigma + P.T @ inv_omega @ P)
    post_mu = post_cov_prior @ (inv_tau_sigma @ pi + P.T @ inv_omega @ Q)
    
    # 4. Апостериорная ковариационная матрица
    post_sigma = sigma + post_cov_prior
    
    # 5. Оптимальные веса
    w_opt = (1 / delta) * np.linalg.inv(post_sigma) @ post_mu
    
    return w_opt, post_mu

# Пример для 3 активов (Apple, Google, Tesla)
cov_matrix = np.array([
    [0.04, 0.02, 0.01],
    [0.02, 0.05, 0.02],
    [0.01, 0.02, 0.08]
])
w_market = np.array([0.5, 0.3, 0.2])

# Взгляд: Tesla превзойдет Apple на 4% (Q = [0.04], P = [-1, 0, 1])
P = np.array([[-1.0, 0.0, 1.0]])
Q = np.array([0.04])

w_bl, mu_bl = black_litterman(w_market, cov_matrix, P, Q)
print("Оптимальные веса Блэка-Литтермана:", np.round(w_bl, 4))
```
